GLOBECONVERT — Currency Converter Dashboard

Cara menjalankan:
1. Ekstrak folder/ZIP ini.
2. Buka folder di VS Code.
3. Buka index.html dengan Live Server, atau buka langsung di browser.
4. Pastikan perangkat terhubung ke internet.

Fitur:
- Konversi mata uang dengan data online dari open.er-api.com
- Daftar mata uang diisi dari API
- Tukar mata uang asal/tujuan
- Tombol refresh kurs
- Pasangan favorit dan riwayat disimpan di localStorage browser
- Tampilan responsif desktop, tablet, Android, iPhone/iPad

Catatan:
- Memerlukan internet untuk kurs online, Google Fonts, dan grafik Chart.js.
- Kurs indikatif, tidak sama dengan jaminan kurs bank/money changer.
- Grafik Top 4 adalah ilustrasi visual, bukan data volume transaksi.
- Tidak ada backend; favorit dan riwayat hanya tersimpan di browser/perangkat ini.
